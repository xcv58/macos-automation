Privacy Policy

Last updated: 2026-08-30. SD Import is a local macOS utility for copying photos and videos from SD cards or selected source folders.

Data stored locally

SD Import stores app settings, security-scoped folder bookmarks, import history, and dedupe records locally. The direct-download edition uses ~/Library/Application Support/SD Import/state.sqlite; the Mac App Store edition uses its macOS app container. The App Store helper and main app share only a sandboxed App Group mailbox for mount events and helper health.

Optional portable import receipts

If you enable portable import receipts, SD Import creates or appends .sd-import/imported-v1.jsonl on writable sources. The hidden ledger contains versioned file fingerprints, relative source paths, sizes, modification and import timestamps, and validation checksums so another Mac can avoid duplicate imports. It does not contain destination paths, usernames, or media contents. The option is disabled by default, read-only sources continue without writing portable history, and ledger access refuses symbolic-link redirection outside the selected source.

Network use

The direct-download edition uses the network for Sparkle update checks when configured. Sparkle is not included in the Mac App Store edition; the App Store delivers its updates. The App Store edition uses Apple StoreKit to load, purchase, and restore the optional lifetime unlock. Apple processes transactions. SD Import has no account or purchase server and does not receive payment details.

Removable media permission

The Mac App Store helper may detect that a removable volume mounted, but it does not enumerate or scan the volume. The main app asks before each newly detected card scan. If access is not already authorized, macOS presents a folder-access panel. Scanning begins only after both steps are accepted, and access is retained locally as a security-scoped bookmark.

No automatic telemetry

SD Import does not send analytics, telemetry, import history, media files, folder listings, or crash reports to the maintainer. Diagnostics export is opt-in and redacted. The direct-download edition can reveal the local macOS crash-report folder or export the latest local SD Import crash report. The sandboxed Mac App Store edition does not browse that system directory. Neither edition uploads crash reports automatically.

Support requests

Public GitHub issues are visible to everyone. Do not attach private photos, videos, full card dumps, credentials, or unredacted logs to public issues.
