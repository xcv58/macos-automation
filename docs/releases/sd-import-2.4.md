# SD Import 2.4

## Changes

- Redesigns History as a side-by-side browser so recent imports and the selected
  job remain visible together.
- Gives imported files the full available height with a simpler filter and a
  single, predictable scroll area.
- Moves secondary job actions into a compact More menu while keeping Retry
  immediately available.
- Opens Version History on the complete GitHub Releases page while keeping
  version-specific notes in Sparkle's update window.
