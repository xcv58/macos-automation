# SD Import 2.6

## Changes

- Redesigns import review into one continuous, native-feeling workspace with a
  clearer source summary, import plan, pinned file controls, and consistent
  list and grid previews.
- Keeps every scanned file available for inspection, including when nothing is
  new to import, and pages large cards to keep browsing responsive.
- Improves import correctness by copying only unambiguously associated
  sidecars and blocking an import when destination free space cannot be
  verified.
- Makes cancellation, retry, receipts, and ejection recovery clearer while
  preserving accurate totals across retry attempts.
- Speeds up large History entries with bounded paging and improves
  accessibility throughout the review flow.
- Refines the macOS window, sidebar, title-bar, onboarding, and empty-state
  presentation for a more consistent native appearance.

## Notes

No settings changes or manual follow-up are required after updating.
