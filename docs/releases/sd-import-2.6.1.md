# SD Import 2.6.1

## Changes

- Keeps the primary Import button visible at the top of the review screen, with
  a clearer readiness summary at the bottom.
- Aligns the Import Plan fields and lets destination paths use wider windows
  while keeping Copy, Save to, and Organize choices compact and easy to scan.
- Prevents a macOS segmented-control crash that could occur while switching
  options in a large file preview.

## Notes

No settings changes or manual follow-up are required after updating.
